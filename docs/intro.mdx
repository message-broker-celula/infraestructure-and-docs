# Introducción

La plataforma "Database-Centric Architecture" sitúa la base de datos como el núcleo de las operaciones: los servicios, las integraciones y la lógica de negocio se diseñan alrededor de modelos de datos consistentes y APIs centradas en los datos.

Esta documentación cubre la arquitectura general y los componentes principales. La plataforma se compone, de forma general, de tres repositorios principales:

- `infraestructure`: Infraestructura y automatización (IaC, despliegue, redes, subdominios y configuración de DNS). Contiene scripts y plantillas para aprovisionar entornos.
- `backend-core`: Servicios backend y APIs que implementan la lógica de negocio, orquestación y puertas de enlace (incluye el `AI Gateway` documentado en la sección de backend-core).
- `data-platform`: Componentes y repositorios que gestionan esquemas, migraciones, backups y conectores hacia los distintos motores de base de datos.

## Arquitectura

La arquitectura Database-Centric prioriza la consistencia y la trazabilidad de los datos. Los servicios están diseñados para exponer contratos claros sobre los modelos de datos y favorecer operaciones que reduzcan la duplicación y las inconsistencias.

Sigue a continuación con la sección de `backend-core` para ver casos concretos, patrones de integración y operaciones de base de datos.
